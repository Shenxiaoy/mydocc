# 提示词工程

实用提示词模板与调优经验。

## 一个通用模板

```
角色：你是一个 [领域] 专家。
任务：[具体任务]。
输入：[输入数据或上下文]。
约束：
  - [约束 1]
  - [约束 2]
输出格式：[期望的结构]。
```

## 三条经验

1. **先说清"做什么"，再说"怎么做"**——任务定义比方法指引更重要
2. **给例子比给规则更有效**——Few-shot 永远好于纯指令
3. **让模型复述任务**——在复杂任务前，让它先重述一遍理解

## 反模式

- 把所有要求堆在一段话里，没有结构
- 用否定句（"不要..."）而非肯定句（"只做..."）
- 期望一次得到最终结果，而非分步骤迭代
