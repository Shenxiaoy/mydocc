# 漫剧制作

## AI漫剧全套工具清单（按制作流程）
 
AI漫剧完整链路：**剧本分镜** → **角色&分镜绘图** → **图片动态化（图生视频/动作迁移）** → **AI配音音效** → **剪辑合成**，分【新手轻量化】【专业进阶本地】【一站式全打包平台】三套方案。
 
### 一、剧本 & 分镜脚本（把小说/脑洞变成镜头脚本）
 
> 输出：镜号、景别、画面描述、台词、情绪、时长，竖屏9:16适配短视频漫剧
 
1. 新手免费
 
- 豆包 / Kimi / DeepSeek：直接提示“生成竖屏漫剧分镜脚本，输出表格，含画面、台词、情绪、镜头运动”，中文网文感好
 
2. 专项工具
 
- 阅文漫剧助手：网文小说一键拆成分镜
- AnimeScript Pro：影视级专业分镜脚本
 
### 二、AI绘图｜角色、分镜原画（解决角色变脸是核心）
 
> 建议先做角色三视图，用参考图锁定人物五官服装，保证全剧画风统一
 
**国内网页（上手最简单，角色锁定）**
 
- 即梦AI：二次元/国漫强，IP‑Adapter角色锁定，适合精品漫剧；自带图生视频能力
- 漫小芽、白日梦AI：专门漫剧，脚本直接批量出分镜图
 
**海外**
 
- Midjourney：画面精致，角色一致性弱，需要反复垫参考图
 
**本地高阶（工作室批量连载）**
 
- ComfyUI：Flux/SD模型，IP‑Adapter、FaceID锁定人脸；可集成动作迁移、图生视频工作流，自由度最高，需要显卡
 
### 三、动态化｜静态漫画图转动漫视频（告别PPT漫剧）
 
两类：①普通图生视频（眨眼、运镜、发丝飘动）；②动作迁移（上传动作参考视频，让漫画人物复刻真人动作，打斗、武打漫剧必备）
 
**图生视频**
 
1. 可灵Kling 3.0：国产，动作稳定性强，运镜流畅，支持首尾帧，漫剧高频使用
2. 即梦Seedance2.0：支持参考视频驱动角色动作，武打漫剧友好，音画同步
3. 海螺AI(Hailuo)：复杂动作、特效表现好
4. Runway Gen‑4（海外）
 
**动作迁移（重点！武打、舞蹈、大幅度动作）**
 
- Scail2：热门动作迁移模型，参考视频驱动漫画人物做动作，ComfyUI可部署
- Wan‑2.2‑Animate：开源动作迁移，HuggingFace可直接跑；上传角色图+动作参考视频生成动画
 
> 小技巧：简单对话镜头直接微动运镜；大幅度打斗镜头优先动作迁移；复杂转场使用首尾帧生视频（起始帧+结束帧，AI补中间画面）
 
### 四、AI配音、音效、BGM
 
1. 剪映内置TTS：免费，情绪音色多，新手首选，可批量导出角色音频
2. ElevenLabs：海外，情绪人声极强，适合旁白；支持音色克隆
3. Fish‑Audio：中文情绪强，支持小样本音色复刻
4. Azure TTS：微软语音，国产漫剧工作室常用
5. 音效素材：爱给网、剪映音效库
 
### 五、后期剪辑合成
 
1. 剪映（CapCut）：绝大多数个人创作者最终收口，导入所有AI视频片段，拼接、字幕、转场、调色、加BGM，直接导出9:16成片，最主流
2. Premiere Pro：专业精细剪辑，适合工作室
 
六、一站式AI漫剧平台（懒人一体化，脚本‑分镜‑绘图‑动画‑配音一键）
 
适合不想折腾多软件，快速出片，缺点精细度不如分开工作流：
 
1. MkAnime AI：漫剧专用，输入故事，自动剧本、分镜、绘图、配音输出漫剧短视频，支持角色锁定 
2. Catimind神经猫AI：工作室常用，长篇连载角色一致性强，完整流水线
3. 纳米漫剧流水线：国产工业化漫剧工具，小说导入自动拆镜，角色资产库复用
4. AniShort：团队协作，多人编辑项目，适合工作室连载漫剧
 
✨两套实操组合方案
 
方案A｜个人新手零成本入门（推荐）
 
全部网页/剪映，不需要显卡
 
1. 脚本：豆包生成漫剧分镜表格
2. 绘图：即梦AI，上传角色三视图锁定人物，批量出分镜图
3. 动态：即梦 / 可灵AI图生视频做镜头动画
4. 配音+剪辑：剪映，配音、字幕、拼接成片
 
方案B｜工作室/追求高质量连载（本地硬件）
 
1. 脚本：Kimi输出结构化分镜JSON
2. 绘图：ComfyUI+Flux+IP‑Adapter/FaceID锁定角色，批量生分镜原画
3. 动画：ComfyUI集成 Scail2动作迁移 + LTX2.3图生视频
4. 配音：Fish‑Audio
5. 剪辑：PR/剪映专业版
 
⚠️关键避坑点
 
1. AI漫剧最大痛点是人物变脸：必须先生成角色三视图，每一轮生成都垫角色参考图；优先带IP‑Adapter/参考图锁定功能的工具。
2. 不要全部文生视频：先出静态关键帧确认画风、人物，再转动态，否则反复抽卡浪费算力。
3. 武打大幅度动作，优先动作迁移；普通对话镜头用普通图生视频微动即可。
