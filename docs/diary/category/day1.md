# AI Agent 定制接单实操路径
以下是面向资深前端开发者的 AI Agent 定制副业完整操作指南，从零基础到第一笔收入，每一步都有具体动作。

## 一、工具选型：先学会用什么搭
作为前端开发者，你有天然优势——理解 API、工作流、前端集成。核心只需要精通以下三个平台中的 1-2 个：

| 平台 | 定位 | 适合场景 | 上手时间 | 成本 |
|------|------|----------|----------|------|
| Coze（扣子） | 零代码，拖拽搭建 | 轻量客服、内容生成、Bot商店分发 | 1-2天 | 免费（500次/天API调用） |
| Dify | 开源，可私有化部署 | 企业知识库问答、RAG系统、深度定制 | 3-5天 | 开源免费，Cloud Pro $59/月 |
| n8n | 开源自动化工作流 | 跨系统数据流转、自动化Pipeline | 3-7天 | 开源免费，Cloud有免费层 |

我的建议：Coze 起步最快，先用它跑通第一个项目；Dify 做企业级客户（尤其对数据安全有要求的）；n8n 做复杂的系统间自动化。三者可以组合使用。

## 二、技能学习路线（2-3 周达到接单水平）
### 第 1 周：Coze 基础
1. 注册 Coze（抖音账号一键登录），跟着官方教程搭 3 个练手 Agent：
    - 小红书标题生成器（练 Prompt 配置）
    - 客服自动回复机器人（练知识库上传 + 对话逻辑）
    - 朋友圈文案生成器（练工作流编排）
2. 掌握核心能力：Prompt 编写、知识库构建（上传 FAQ/产品文档）、插件调用、工作流节点设计
3. 尝试发布到 Bot 商店，观察用户调用数据

### 第 2 周：Dify + RAG
1. 用 Docker Compose 本地部署 Dify（半天搞定）：
```text
git clone https://github.com/langgenius/dify.git
cd dify/docker
cp .env.example .env
docker compose up -d
```
2. 搭建一个"企业内部知识库问答"Agent：上传 PDF/Word 文档 → 自动分段向量化 → 用户提问 → 精准回答
3. 学会 API 集成：Dify 每个应用自动生成 REST API，用你的前端能力做一个漂亮的对话界面对接

## 第 3 周：n8n + 系统集成
1. 本地部署 n8n（Docker 一键启动）
2. 搭建 3 个经典工作流：
    - 表单提交 → 自动录入 CRM → 发 Slack/飞书通知
    - 定时抓取竞品价格 → 变动时自动通知
    - Shopify 新订单 → 自动同步到 Google Sheets + 发确认邮件
3. 理解 Webhook、API 调用、数据转换、条件分支等核心概念

## 三、找到你的第一个客户

### 渠道 1：闲鱼/小红书（最快出单）
- 闲鱼挂服务："AI 智能客服定制，帮你的店铺实现 7×24 自动回复"
- 定价：搭建费 500-2000 元 + 月维护 200-500 元
- 标题关键词：AI客服、自动回复、智能机器人、Coze定制
- 前 3-5 单低价跑评价（300-500 元/单），评价上来后涨价

### 渠道 2：Reddit 主动出击（美元收入）
- 蹲守 r/smallbusiness、r/entrepreneur、r/ecommerce、r/forhire
- 搜索关键词："automate"、"chatbot"、"AI tool"、"save time"、"repetitive"
- 不要直接推销，先回答他们的问题，给出具体方案，最后加一句"I actually built something similar for a client, happy to share"
- Fiverr 上挂 AI Agent 定制服务，定价 $200-800/项目

### 渠道 3：本地商家地推（高转化率）
- 目标：餐饮店、教培机构、美业门店、电商卖家
- 话术核心："你每天花多少时间回复客户咨询？我可以帮你搭一个 AI 自动回复，7×24 在线，每月帮你省下 XX 小时"
- 免费试用策略：先免费帮一家搭一个 demo，效果好再收费 + 让他帮你转介绍

## 四、定价策略（2026 年市场行情）

### 国内市场
| 项目类型 | 搭建费 | 月维护费 | 交付周期 |
|----------|--------|----------|----------|
| 简单客服 Bot（Coze） | 500-2,000 元 | 200-500 元 | 1-3 天 |
| 知识库问答系统（Dify） | 3,000-10,000 元 | 500-1,000 元 | 3-7 天 |
| 自动化工作流（n8n） | 2,000-8,000 元 | 300-800 元 | 3-5 天 |
| 企业级 Agent 定制 | 10,000-50,000 元 | 1,000-3,000 元 | 1-4 周 |
| 多 Agent 协作系统 | 30,000-100,000 元 | 3,000-5,000 元 | 2-8 周 |

### 海外市场（Upwork/Fiverr/直接客户）
| 项目类型 | 收费 |
|----------|------|
| AI chatbot setup | $400-1,500 一次性 |
| n8n automation workflow | $100-1,000/项目 |
| Multi-agent system | $5,000-15,000 |
| 月度维护 retainer | $150-500/月 |
| 时薪（AI Agent 开发者） | $50-150/h（Upwork 2026 数据） |

### 定价核心原则
- 按价值定价，不按工时定价。客户在意的是"省了多少人力/时间"，不是你花了几个小时搭建
- 搭建费 + 月维护费组合最稳，月维护费是复利收入
- 同一套方案可以卖给同行业多家客户（标准化后复用）

## 五、交付流程标准化（SOP）
```text
1. 需求沟通（30分钟）
   → 了解客户业务痛点、日常工作流、重复性任务
   → 判断是否适合 AI Agent（不是所有需求都适合）

2. 方案设计（1-2小时）
   → 画出工作流图
   → 选定平台（Coze/Dify/n8n）
   → 列出需要对接的数据源和 API
   → 给客户看方案 + 报价

3. 签约收款
   → 电子合同（明确功能范围、交付标准、售后条款）
   → 预收 30-50% 定金
   → 用飞书/腾讯文档做项目管理

4. 搭建开发（1-7天）
   → 搭建 Agent 工作流
   → 构建知识库（整理客户提供的 FAQ/文档）
   → 对接客户现有系统（微信/企微/CRM 等）

5. 测试交付
   → 内部测试 + 客户 UAT
   → 培训客户使用（录个操作视频）
   → 收尾款

6. 运维（持续）
   → 月度巡检（检查工作流运行状态）
   → Prompt 调优（根据实际对话数据优化）
   → 知识库更新
```

## 六、从"卖时间"到"卖系统"的跃迁路径

### 这是 AI Agent 副业最重要的思维转变：
- 第 1 阶段：接单型（月入 3,000-8,000 元）
- 一对一帮客户搭建定制 Agent
- 每个项目花 2-7 天
- 收入和时间成正比
### 第 2 阶段：产品化（月入 8,000-20,000 元）
- 把做过的定制项目抽象成行业模板
- 同一套"教培机构 AI 答疑系统"卖给 10 家机构
- 搭建费降到 800 元/家 + 月维护 300 元，但量上来了
### 第 3 阶段：SaaS 化（月入 20,000+ 元）
- 把模板打包成自助服务，上架 Coze Bot 商店或自建网站
- 客户自助购买 + 配置，你只需维护系统
- 定价 299-999 元/套 或 99-299 元/月订阅
- 真实案例：有人从闲鱼单笔 50 元起步，6 个月后稳定月入 4.5 万。关键是把"1 小时的产出变成可以卖 100 次的产品"。

## 八、你的前端优势怎么发挥
```
作为资深前端，你比普通 AI Agent 搭建者多出来的能力：
自定义 UI：Dify/n8n 产出的 Agent 需要嵌入客户网站/App，你能做出漂亮的对话界面，而不是给客户一个丑陋的默认页面
API 集成：你理解 REST/GraphQL，能对接客户的各种内部系统
全栈交付：Agent 后端 + 前端界面 + 部署上线，你一个人就能搞定，不用找人配合
产品化能力：用 Next.js + Dify API 做一个完整的 SaaS 产品，这是普通零代码玩家做不到的
```

## 九、避坑清单
```
不做"通用 AI 助手"——大厂已经包场，垂直场景才有生存空间
必须构建 50-200 条垂直知识库——知识库质量决定 Agent 好不好用
保留人工转接机制——AI 处理不了的自动转人工，别让客户卡在死循环里
先收定金再开工——不预付的项目纠纷率极高
注意合规——国内运营需接入通过网信办备案的大模型（通义千问、DeepSeek 等）
不要承诺"100% 准确"——跟客户说清楚 AI 的能力边界
```
